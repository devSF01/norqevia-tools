CSVヘッダー比較

2つのCSVの列名と列順を比較して、列構成の違いを確認できます。

使い方

  1. UTF-8形式のCSVファイルAとCSVファイルBを選択します。
  2. 各ファイルの概要で、ファイル名・サイズ・列数・データ行数を確認します。
  3. 「ヘッダーを比較」を押します。
  4. Aのみ・共通・Bのみの列と、列順の差異を確認します。

入力例

A: ID,NAME,DEPARTMENT B: NAME,ID,DEPARTMENT Aのみ: なし 共通: ID / NAME / DEPARTMENT Bのみ: なし 列順: 異なる（1列目と2列目が入れ替わっています）

仕様・制限

UTF-8（BOM付きも可）のカンマ区切りCSVに対応しています。quoted comma、escaped quote、改行を含むフィールドを読み込めます。Shift_JIS / CP932、TSV、セミコロン区切りには対応していません。ヘッダー行が必要で、CSVの構文と各行の列数も検証します。列名は完全一致で比較し、trim、大文字小文字の変換、Unicode normalization、類似名の推測は行いません。空ヘッダーや重複ヘッダーは元の文字列と出現個数を保ちます。比較するのはヘッダーだけで、データ行の内容は比較しません。元CSVは変更せず、比較結果のDownload機能もありません。

よくある質問

データ行の内容も比較しますか？

いいえ。比較対象はヘッダーの列名と列順だけです。CSVとして読み込めるか確認するため、構文と各行の列数は検証します。

大文字小文字は区別しますか？

はい。「ID」と「id」は異なる列名として扱います。

列順が違うだけでも差異になりますか？

はい。列名の集合が同じでも、列順が違えば完全一致ではありません。差異の位置は1始まりで表示します。

同じ列名が複数あるCSVはどう扱いますか？

重複を削除せず、出現個数を含めて比較します。たとえばAに「ID」が2列、Bに1列ある場合、A側にIDが1列多い差異として表示します。

ファイルはアップロードされますか？

いいえ。ファイルの読み込み・検証・比較はブラウザ内だけで行い、外部へ送信しません。

元CSVは変更されますか？

いいえ。元CSVは読み取り専用で扱い、ファイルの内容を書き換えたり保存したりしません。
