CSV列名変更

CSVの列名だけを変更し、データ内容を変えずに新しいCSVとして保存できます。

●
ブラウザ内で処理します選択したCSVファイルはサーバーへ送信・保存されません。

CSVの列名を変更する

UTF-8 / UTF-8 BOM付きCSVに対応しています。Shift_JIS / CP932には対応していません。

現在の列名と新しい列名

入力した文字列をそのまま新しいヘッダーに使用します。空文字列や重複も指定できます。

使い方

  1. UTF-8形式のCSVファイルを選択します。
  2. 各列の「新しい列名」を編集します。
  3. 「列名を変更」を押し、プレビューを確認します。
  4. 「CSVを保存」を押して新しいCSVを保存します。

入力例

現在の列名: ID / NAME / 部署 新しい列名: 顧客ID / 氏名 / 担当部署 データ行はそのまま、ヘッダーだけが置き換わります。

仕様・制限

すべての列を列番号と現在の列名で一覧表示し、新しいヘッダー名を入力できます。入力文字列はtrimや大小文字変換などをせず、そのまま採用します。空文字列ヘッダーや重複した新ヘッダーも許可します。データ行、値、列順、行順は保持し、変更がない場合も新しいCSVを作成します。出力はUTF-8 BOM付き・CRLF改行です。

よくある質問

重複した列名を入力できますか？

はい。列番号で編集対象を区別できるため、重複した新しい列名もそのまま使用できます。

空の列名を入力できますか？

はい。空文字列も新しいヘッダーとして許可します。

データの値は変わりますか？

いいえ。変更するのはヘッダー行だけです。

入力した内容は送信されますか？

いいえ。読み込み、列名変更、CSV作成はブラウザ内だけで行います。
