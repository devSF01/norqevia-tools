CSV空欄セルチェック

CSV内の空欄セルを列ごと・行ごとに確認し、空欄の位置と件数をチェックできます。

●

使い方

  1. UTF-8形式のCSVファイルを選択します。
  2. 「空欄セルをチェック」を押します。
  3. 空欄セル総数と列別件数を確認します。
  4. CSV行番号・列名・列番号から空欄位置を確認します。

入力例

ID,NAME,EMAIL 001,田中,tanaka@example.com 002,鈴木, 003,,sato@example.com 空欄セル: 2件 EMAIL: 1件 NAME: 1件 CSV行番号: 3行目 EMAIL / 4行目 NAME

仕様・制限

ヘッダー行を除くデータ行の全セルを検査します。値が厳密に空文字列（""）のセルだけを空欄として扱い、半角スペース・全角スペース・タブ・0・NULL・N/A・-は空欄扱いしません。trim、型変換、Unicode normalization、全角半角変換などの暗黙変換は行いません。CSVの内容は変更せず、検査結果のDownload機能もありません。UTF-8（BOM付きも可）のカンマ区切りCSVに対応し、Shift_JIS / CP932、複数ファイル一括検査には対応していません。

よくある質問

スペースだけのセルも空欄になりますか？

いいえ。半角スペース、全角スペース、タブなどの文字が入っているセルは空欄になりません。

NULL や N/A は空欄になりますか？

いいえ。文字が入っているため、空欄ではない値として扱います。

ヘッダーの空欄もチェックしますか？

いいえ。検査対象はヘッダーを除くデータ行のセルだけです。

CSVを自動で修正しますか？

いいえ。空欄の検出と表示だけを行い、CSVを修正・削除・保存する機能はありません。

大量に空欄がある場合は全部表示されますか？

空欄セル総数と列別件数は集計し、位置一覧は先頭100件まで表示します。画面への全件描画は行いません。

ファイルはアップロードされますか？

いいえ。ファイルの読み込みと検査はブラウザ内だけで行い、入力データや検査結果を外部へ送信しません。

元CSVは変更されますか？

いいえ。元ファイルは変更せず、検査結果を表示するだけです。
