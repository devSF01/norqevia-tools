CSV→JSON変換

CSVの各行をJSONオブジェクトへ変換し、JSONファイルとして保存できます。

●
ブラウザ内で処理します選択したCSVファイルはサーバーへ送信・保存されません。

CSVをJSONに変換する

UTF-8 / UTF-8 BOM付きCSVに対応しています。Shift_JIS / CP932には対応していません。

使い方
  1. UTF-8形式のCSVファイルを選択します。
  2. 「JSONに変換」を押します。
  3. 先頭数件のJSONプレビューを確認します。
  4. 「JSONを保存」を押して新しいファイルを保存します。

    
入力例
ID,NAME,ACTIVE
001,田中,true
002,鈴木,

[
  {
    "ID": "001",
    "NAME": "田中",
    "ACTIVE": "true"
  }
]

    
仕様・制限
CSVのヘッダーをJSON objectのkey、各データ行をvalueとしてJSON配列へ変換します。すべての値は文字列として出力し、「001」は文字列のまま、「true」や「null」に見える値も文字列のまま、空欄は空文字列にします。数値・boolean・nullへの型推測は行いません。key順とデータ行順はCSVの順序を保ちます。重複ヘッダーは安全に変換できないため停止し、勝手なrenameは行いません。空ヘッダーは許可しますが、複数ある場合は重複として停止します。出力はUTF-8、BOMなし、整形済みJSON、末尾改行ありです。

    
よくある質問
「001」は数値になりますか？
いいえ。「001」はJSON文字列の「001」として保持します。
重複したヘッダーはどうなりますか？
変換を停止し、重複ヘッダーがあるため変換できないことを表示します。列名を自動変更することはありません。
空のヘッダーは使えますか？
1つだけなら使えます。複数の空ヘッダーは同じkeyになるため停止します。
入力した内容は送信されますか？
いいえ。読み込み、変換、JSON作成はブラウザ内だけで行います。
