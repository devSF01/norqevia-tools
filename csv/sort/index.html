CSV並べ替え

指定した列をキーに、CSVの行を昇順または降順で並べ替えて新しいCSVとして保存できます。

●
ブラウザ内で処理します選択したCSVファイルはサーバーへ送信・保存されません。

CSVの行を並べ替える

UTF-8 / UTF-8 BOM付きCSVに対応しています。Shift_JIS / CP932には対応していません。

使い方

  1. UTF-8形式のCSVファイルを選択します。
  2. 並べ替える列を1つ選び、昇順または降順を選択します。
  3. 「並べ替える」を押します。
  4. プレビューを確認して「CSVを保存」を押します。

入力例

ID,NAME 003,鈴木 001,佐藤 002,田中 ID列を昇順で並べ替えると、次のようになります。 ID,NAME 001,佐藤 002,田中 003,鈴木

仕様・制限

指定した1列の値を文字列のまま比較し、昇順または降順でデータ行を並べ替えます。数値・日付への自動変換、自然順、大文字小文字の変換、trim、Unicode normalization、全角半角変換は行いません。たとえば「001」と「1」は別の文字列として扱います。同じキー値の行は元の相対順序を維持します。ヘッダーは常に先頭に残り、元CSVは変更しません。UTF-8（BOM付きも可）のカンマ区切りCSVに対応し、出力はUTF-8 BOM付き・CRLF改行の新しいCSVです。Shift_JIS / CP932、複数列キー、複数ファイル処理には対応していません。

よくある質問

数字は数値として並びますか？

いいえ。文字列として比較します。「001」と「1」は別の文字列なので、数値としての大小や自然順にはなりません。

日付は日付順になりますか？

いいえ。日付への自動変換はせず、CSVに書かれた文字列の順序で並べ替えます。

同じ値の行はどうなりますか？

キー列の値が同じ行は、元のCSV内での相対順序を維持します。

空欄はどう扱われますか？

空欄も通常の文字列として比較します。空欄を先頭または末尾に固定する特別な設定はありません。

複数列で並べ替えできますか？

いいえ。今回対応するキー列は1列だけです。

ファイルはアップロードされますか？

いいえ。ファイルの読み込み、並べ替え、CSV作成はブラウザ内だけで行い、入力データや処理結果を外部へ送信しません。

元CSVは変更されますか？

いいえ。元ファイルは変更せず、並べ替えた内容を新しいCSVとして保存します。
