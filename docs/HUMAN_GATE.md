# Human Gate checklist

実装後の自動検証と公開承認の手順は [`docs/PUBLISH_PROCEDURE.md`](PUBLISH_PROCEDURE.md) に従います。ユーザーが対象Toolについて「公開してください」と明示した場合、そのメッセージを公開に進むためのHuman Gate最終承認として扱います。ただし、個別チェックボックスは実際に人が確認した項目だけを `[x]` にし、未実施の目視確認を自動的に完了扱いにしません。

## Tool #001: 2つのリスト突合

- [ ] Excelから1列を貼り付けて正常に動く
- [ ] Aのみ / 共通 / Bのみが直感どおり
- [ ] 重複件数が理解しやすい
- [ ] 日本語表示が自然
- [ ] コピーが正常
- [ ] TXT保存が正常
- [ ] 入力内容が外部送信されていない
- [ ] PC表示に問題がない
- [ ] スマートフォンで致命的な崩れがない
- [ ] 説明文と挙動が一致している

## Tool #002: CSV列抽出・列削除

以下の5項目だけを人間が確認します。

- [ ] Excel等で作成した日本語UTF-8 CSVを選択して正常に読み込める
- [ ] 列選択UIが直感的に理解できる
- [ ] Previewが実務上確認しやすい
- [ ] 保存したCSVをExcelで開き、日本語・先頭ゼロに問題がない
- [ ] PC上の見た目・日本語表現に違和感がない

### Tool #002で自動確認済み

外部通信、Console Error、主要URLのHTTP応答、基本レスポンシブoverflow、CSV構文・列抽出の正常系と異常系、UTF-8 BOM、ダウンロード、Offline動作は自動テストで確認します。Tool #001の10項目から、Tool #002の人間確認は5項目へ削減しました。
