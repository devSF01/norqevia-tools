# Human Gate checklist

- [ ] Excelから1列を貼り付けて正常に動く
- [ ] Aのみ / 共通 / Bのみが直感どおり
- [ ] 重複件数が理解しやすい
- [ ] 日本語表示が自然
- [ ] コピーが正常
- [ ] TXT保存が正常
- [ ] 入力内容が外部送信されていない
- [ ] PC表示に問題がない
- [ ] スマートフォンで致命的な崩れがない
- [ ] 説明文と挙動が一致している
